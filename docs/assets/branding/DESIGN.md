# heiccy 디자인 기준

## Overview

### 문서 범위와 디자인 방향

이 문서는 [Google DESIGN.md 명세](https://github.com/google-labs-code/design.md/blob/main/docs/spec.md)의 `alpha` 형식에 따라 확정된 브랜드 에셋과 macOS 앱의 시각 적용 기준을 정리한다. 표준 섹션명과 YAML 키는 도구 호환성을 위해 영문으로 유지하고, 설명은 한국어로 작성한다.

작은 눈과 미소를 가진 클립보드, 둥근 획과 소문자 워드마크로 헤이키의 친근하고 재치 있는 성격을 표현한다. 브랜드의 개성은 로고와 심볼에 담고, 앱 본문과 조작 요소는 기존 시스템 글꼴과 표현을 사용해 읽고 조작하기 쉽게 유지한다. 이 문서의 적용 범위는 브랜드 에셋·메뉴바 심볼·패널 헤더·앱 아이콘이다.

### 이름과 소개 문구

- 영문 브랜드명: **heiccy**. 워드마크에서는 소문자를 유지한다.
- 한국어 발음: **헤이키**.
- 소개 문구: **HEIC를 JPEG·PNG로, 알아서.** / **변환은 헤이키에게.**

이 문서는 확정된 브랜드 에셋과 앱의 시각 적용 기준을 기록한다. 앱의 표시 이름과 패널 서비스명은 소문자 `heiccy`를 사용한다. 배포 앱은 `heiccy.app`, DMG는 `heiccy-0.3.0-arm64.dmg`, 볼륨 이름은 `heiccy`다. 내부 실행 파일 `HEICConverter`, 번들 ID, PyPI·CLI 이름과 기존 `~/Pictures/HEIC Converter` 출력 폴더는 호환성을 위해 유지한다.

## Colors

### 에셋 색상과 역할

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `colors.primary` | `#000000` | 가로 로고, 투명 심볼, 흰 타일 안의 클립보드에 사용하는 검정 |
| `colors.icon-tile` | `#FFFFFF` | 패널 심볼과 앱 아이콘의 흰 타일 |

검정 심볼은 흰색 또는 충분히 밝은 배경에 사용한다. 어두운 배경에서는 흰 타일을 포함한 앱 아이콘을 사용한다. 가로 로고와 1:1 심볼의 배경, 앱 아이콘의 흰 타일 바깥은 투명하게 유지한다.

### 시스템이 처리하는 색상

메뉴바는 `NSImage` 템플릿 이미지로 제공하므로 시스템이 밝기와 상태에 따라 표시 색상을 처리한다. 검정 원본 색상을 메뉴바의 최종 표시 색상으로 고정하지 않는다. 패널 워드마크는 `.primary`를 사용해 밝은 환경에서는 검정, 어두운 환경에서는 흰색을 기본으로 표시한다. 본문의 색상 토큰을 앱 전체의 배경·텍스트·버튼 색상으로 확대 적용하지 않는다.

## Typography

확정 글꼴은 **Comic Sans MS Regular**다. `heiccy-logo.svg`의 서비스명은 실제 글꼴을 CoreText로 윤곽 변환한 벡터이며, 글꼴 파일을 앱에 번들하지 않는다. SVG와 PNG를 사용할 때 해당 글꼴을 별도로 설치할 필요가 없다.

Comic Sans MS는 가로 로고와 패널 헤더의 워드마크에 사용한다. 앱 본문, 버튼, 설정과 상태 문구에는 기존 시스템 글꼴을 유지한다. 워드마크를 다른 글꼴로 다시 입력하거나 굵게 처리하지 않는다.

가로 로고는 왼쪽에 클립보드 심볼, 오른쪽에 서비스명을 배치한다. 아이콘의 둥근 끝과 선 굵기는 워드마크의 도톰한 획에 맞춘다. 확정 SVG의 간격과 글자 윤곽을 그대로 사용한다.

워드마크는 일반 텍스트가 아니라 확정 글자 윤곽을 사용하는 에셋이다. YAML의 `typography` 토큰은 생략하고 그 이유를 `omitted`에 기록한다. 패널 워드마크의 출력 크기와 구현은 `Components`의 패널 좌상단 기준을 따른다.

## Layout

### 단위와 토큰 적용 범위

YAML의 `spacing`, `rounded`, `components` 크기 토큰은 **1024×1024px 앱 아이콘 에셋**에만 적용한다. `spacing.app-icon-inset`은 캔버스 각 변에서 흰 타일까지의 **96px** 여백이다. `components.app-icon-tile`은 **832×832px** 타일의 크기·색상·모서리를 정의한다. 앱 전체의 공통 간격 척도로 사용하지 않는다.

macOS 화면의 `pt`, 이미지 에셋의 `px`, **18×20 기하 좌표계**의 수치를 구분한다. Google 명세의 크기 토큰 단위는 `px`·`em`·`rem`이므로 메뉴바·패널의 `pt` 값과 기하 좌표는 본문에 유지한다. 화면 배율을 고려하지 않고 `pt`를 `px`로 치환하지 않는다.

### 로고와 패널 정렬

가로 로고의 심볼·서비스명 배치와 간격은 확정 SVG를 따른다. 1:1 캔버스에서도 세로로 긴 클립보드 비율을 유지하며, 로고와 심볼은 가로·세로를 같은 배율로 조절한다.

헤더는 아이콘 타일과 워드마크를 수직 중앙에 배치하고 워드마크에 **아래로 3pt**의 시각 보정을 적용한다. `y`의 아래 꼬리를 포함한 전체 경계보다 글자 본체의 중심을 기준으로 맞추기 위한 값이다. 24pt 출력에서 꼬리를 제외한 글자 본체의 경계 중심은 전체 중심보다 약 2.83pt 위에 있다. 로고 원본의 윤곽과 패널 높이는 그대로 유지한다.

## Elevation & Depth

로고·심볼·흰 타일에는 회색 테두리, 그림자 또는 추가 장식을 넣지 않는다. 검정 심볼과 흰 타일의 대비로 형태를 구분한다. 이 규칙은 브랜드 에셋과 헤더의 심볼 타일에 적용하며, 시스템이 앱 아이콘 표시에 적용하는 효과나 기존 패널의 창 표현을 별도로 변경하는 기준은 아니다.

## Shapes

### 클립보드 심볼

작은 눈 두 개와 짧은 미소가 있는 검정 클립보드다. 클립보드 자체는 세로로 긴 형태를 유지하고, 1:1 출력에서도 도형을 정사각형으로 늘리지 않는다.

아래 값은 **18×20 기하 좌표계**의 수치다. 외곽선까지 포함한 출력 크기와 중심선 크기는 서로 다르다.

| 항목 | 확정 값 |
| --- | --- |
| 클립보드 중심선 너비 | 13.25 (`x=2.375…15.625`) |
| 클립보드 중심선 높이 | 17.5 (`y=1.25…18.75`) |
| 외곽과 입의 선 굵기 | 1.30 |
| 선 끝·꺾임 | 둥글게 처리 |
| 눈 중심 | `(6.25, 10.9)`, `(11.75, 10.9)` |
| 눈 반지름 | 0.72 |
| 입 경로 | `M7.85 12.4 Q9 13.55 10.15 12.4` |
| 기본 색상 | 검정 `#000000` |

일반 에셋은 전체 도형과 획을 같은 배율로 축소한다. 메뉴바의 16.2×18pt 출력에서 외곽 선 굵기는 1.17pt이며, 얼굴에는 아래의 작은 크기용 보정을 적용한다.

### 흰 타일

패널의 흰 타일은 **34×34pt**, 모서리 반지름은 **8pt**다. 앱 아이콘의 흰 타일은 **832×832px**, 모서리 반지름은 `{rounded.app-icon-tile}`(**180px**)다. 두 타일은 서로 다른 출력 용도의 규격이며, 패널 타일에 앱 아이콘의 모서리 토큰을 사용하지 않는다.

앱 아이콘의 라운드 사각형은 프로젝트에서 정한 타일 형태이며 Apple 공식 스쿼클 템플릿과 정확히 일치한다고 전제하지 않는다.

## Components

### 메뉴바

`PhotoClipboardIconGeometry`의 클립보드 외곽을 사용하고 얼굴을 작은 크기에 맞춰 보정한다. 출력 크기는 **16.2×18pt**이며, `NSImage` 템플릿 이미지로 제공해 시스템이 메뉴바의 밝기와 상태에 맞춰 색상을 처리하도록 한다. 흰 타일과 워드마크는 넣지 않는다.

아래 값은 18×20 기하 좌표계 기준이며 메뉴바에만 적용한다. 눈과 미소의 간격을 확보하면서 눈의 지름과 미소의 폭을 키운다.

| 항목 | 메뉴바 보정 값 | 실제 16.2×18pt 출력 |
| --- | --- | --- |
| 눈 중심 | `(6.25, 10.2)`, `(11.75, 10.2)` | 원본보다 위로 0.63pt 이동 |
| 눈 반지름 | 1.10 | 지름 1.98pt, 원본 대비 약 53% 확대 |
| 입 경로 | `M7 13.1 Q9 15.2 11 13.1` | 끝을 포함한 폭 4.95pt |
| 입 선 굵기 | 1.50 | 1.35pt |

패널과 앱 로고에는 원본 얼굴을 사용한다. 메뉴바 얼굴 보정은 브랜드 SVG·PNG·ICNS를 변경하는 작업이 아니다.

자동 변환이 일시정지된 경우 기존 일시정지 배지와 옅은 심볼 표현을 유지한다. 작은 크기에서도 눈·입과 집게가 구분되는지는 실제 1x·2x 출력에서 확인한다.

### 패널 좌상단

검정 심볼을 **22×24pt**로 표시하고, **34×34pt** 흰 타일 안에 배치한다. 타일 모서리 반지름은 **8pt**로 정하며 회색 테두리는 제거한다. 메뉴바와 같은 클립보드 외곽과 원본 얼굴을 사용한다.

패널의 서비스명은 `HeiccyWordmark`로 표시한다. 확정 `heiccy-logo.svg`의 Comic Sans MS Regular 글자 윤곽을 SwiftUI 벡터 도형으로 옮겨 **높이 24pt·너비 약 64.51pt**로 그린다. 글꼴 파일이나 이미지 리소스를 별도로 번들하지 않아 다른 Mac에서도 같은 모양을 표시한다. 밝은 환경은 검정, 어두운 환경은 흰색을 기본으로 하는 `.primary` 색상으로 그리며 접근성 이름은 `heiccy`로 유지한다. 워드마크 전용 Comic Sans MS를 앱 본문 글꼴로 확대 적용하지 않는다.

### 앱 아이콘

1024×1024 캔버스에 흰 타일을 `x=96`, `y=96`, `width=832`, `height=832`, `rx=180`으로 배치한다. 타일 바깥은 투명이며 회색 테두리는 넣지 않는다. 심볼은 기존 1:1 SVG와 동일한 `translate(188 152) scale(36)` 배치를 사용한다.

이 라운드 사각형은 프로젝트에서 정한 타일 형태이며 Apple 공식 스쿼클 템플릿과 정확히 일치한다고 전제하지 않는다. 실제 Dock·Finder 출력에서 여백과 모서리 형태를 확인한다.

`packaging/macos/create_icon.py`는 `heiccy-app-icon.png`를 읽어 Pillow의 LANCZOS 축소로 16·32·128·256·512pt의 1x·2x PNG 10개를 생성한다. `build.sh`는 `iconutil`로 이를 변환해 앱 번들의 `Contents/Resources/AppIcon.icns`에 넣는다. 가장 큰 표현은 1024×1024다. 기존 투명 심볼 ICNS를 흰 타일 앱 아이콘 대신 사용하지 않는다.

### 에셋별 역할

| 파일 | 용도 | 캔버스·배경 |
| --- | --- | --- |
| `heiccy-logo.svg` | 가로 로고의 벡터 원본 | 2171×650, 투명 |
| `heiccy-logo.png` | 가로 로고의 래스터 이미지 | 2171×650, 투명 |
| `heiccy-logo-square.svg` | 심볼만 사용하는 1:1 벡터 원본 | 1024×1024, 투명 |
| `heiccy-logo-square.png` | 심볼만 사용하는 1:1 이미지 | 1024×1024, 투명 |
| `heiccy-logo-square.icns` | 투명 심볼의 macOS 아이콘 형식 | 여러 출력 크기 |
| `heiccy-app-icon.svg` | 앱 아이콘의 벡터 원본 | 1024×1024, 흰 타일 바깥 투명 |
| `heiccy-app-icon.png` | 앱 패키징에 사용하는 원본 | 1024×1024, 흰 타일 바깥 투명 |
| `heiccy-app-icon.icns` | 앱 번들과 동일한 macOS 아이콘 | 여러 출력 크기 |
| `index.html` | 로컬 미리보기와 에셋 다운로드 | 검토용 화면 |

투명 심볼과 흰 타일을 포함한 앱 아이콘은 용도가 다르므로 별도 파일로 관리한다. 앱 아이콘은 워드마크를 넣지 않는다.

## Do's and Don'ts

### 사용 규칙

- 로고와 심볼을 사용할 때 가로·세로를 동일한 배율로 조절하고, 투명 여백을 포함한 전체 에셋을 보존한다.
- 검정 심볼은 흰색 또는 충분히 밝은 배경에 사용한다. 어두운 배경에서는 흰 타일을 포함한 앱 아이콘을 사용한다.
- 회색 테두리, 그림자, 임의의 추가 색상이나 글자 외곽선을 넣지 않는다.
- 워드마크는 소문자 `heiccy`와 확정 Comic Sans MS Regular 윤곽을 사용한다. 다른 글꼴로 다시 입력하거나 굵게 처리하지 않는다.
- 메뉴바의 얼굴 보정은 메뉴바에만 적용하고, 패널·브랜드 에셋에는 원본 얼굴을 사용한다.
- 투명 심볼 ICNS와 흰 타일 앱 아이콘 ICNS는 각각의 용도로 사용한다.

### 갱신 절차

- 기하를 변경할 때 SVG 원본과 `PhotoClipboardIconGeometry`를 함께 맞춘 뒤 PNG와 ICNS를 다시 생성한다. 래스터 파일만 직접 수정하지 않는다.
- 글꼴 윤곽을 다시 생성해야 한다면 Comic Sans MS Regular를 사용하고, 기존 워드마크의 글자 간격과 배치를 대조한다.
- 워드마크 윤곽을 변경할 때 `HeiccyWordmark.swift`도 확정 SVG의 글자 경로와 맞춘다. 패널 크기 조절은 윤곽과 별도로 하며 가로·세로 비율을 유지한다.
- 에셋을 바꾼 뒤 `index.html`의 미리보기·다운로드 대상과 이 문서의 파일명을 함께 확인한다.

### 검증과 기록

메뉴바의 일반·일시정지 상태, 패널 헤더의 밝은·어두운 환경, 앱 아이콘의 시스템 표시를 검토한다. 릴리스 전에 실제 표시 상태를 확인하고 미검증 항목을 구분한다. 빌드·설치 방법은 [공개 빌드 안내](../../build.md)를 참고한다.

이 문서의 수치는 제작·적용 기준이며, 모든 표시 환경에서 검증이 끝났음을 뜻하지 않는다. 릴리스 검증에서 실제 확인 결과와 미검증 항목을 구분한다. 이 문서의 YAML과 본문을 변경할 때는 해당 색상·크기·기하 값이 서로 일치하는지 확인한다.
