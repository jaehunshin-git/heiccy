# heiccy 입력과 붙여넣기 호환성

Apple Silicon arm64·macOS 15 이상에서 읽을 수 있는 로컬 일반 `.heic` 파일 URL과
raw `public.heic` 데이터를 지원합니다. 원본 파일은 변경하지 않으며 클립보드 이력은
저장하지 않습니다. 혼합 항목과 비HEIC 항목의 순서 및 보존할 수 있는 표현을
유지하며, 동영상은 HEIC 미리보기가 함께 있어도 변환하지 않습니다.

Photos에서 지원하는 HEIC 사진을 직접 복사할 수 있으며 별도로 내보낼 필요가
없습니다. 사진 입력은 유효한 raw HEIC 데이터를 우선 사용합니다. `.photoslibrary`
내부 URL은 raw 유무와 관계없이 파일이나 파일시스템 메타데이터를 읽지 않습니다.
보관함 내부 URL에 raw HEIC가 없으면 원본 데이터가 있는 사진을 다시 복사하도록 안내합니다.
raw가 없을 때의 URL 대체 입력은 보관함 밖의 읽을 수 있는 로컬 일반 HEIC 파일에만
적용합니다. 이 파일은 오프라인 상태가 아니고 실제 데이터가 로컬에 있어야 합니다
(`dataless`가 아님). Photos의 파일 URL 대체 입력은 부모 경로의 심볼릭 링크도
허용하지 않습니다. 보관함 밖에서 Photos 자산 참조 없이 파일 URL만 있는 입력은
Finder 파일과 같은 로컬 파일 검사·읽기 경로로 처리합니다.
확보한 HEIC 바이트는 앱이 소유한 별도 파일로 처리하므로 Photos 원본 사진을
수정하지 않습니다.
변환한 Photos 사진의 출력에서는 불투명한 Photos 자산 참조를 제거합니다.

모든 HEIC 변환이 성공하고 같은 복사 내용이 유지될 때만 결과를 클립보드에
게시합니다. 실패·취소·일시정지·새 복사는 이전 결과의 게시를 막습니다.
정상 종료 시 클립보드가 여전히 앱 소유의 결과이면 혼합 항목을 포함한 전체
클립보드를 복구합니다. 사용자가 새로 복사한 클립보드는 덮어쓰지 않습니다.
Photos 사진은 원본 HEIC 바이트와 일반 캡션을 유지하고, 자산 참조와 동적·비공개
Photos 참조를 제거한 형태로 정규화해 복원합니다. 파일 URL은 앱 소유의 안정적인
임시 HEIC 파일로 연결하며, 이 파일은 정상 종료 뒤에도 클립보드가 참조하는 동안
유지합니다. 이는 같은 사진 내용과 동등한 원본 HEIC의 복원이며, 동일한 Photos
내부 URL이나 Photos 자산 선택 의미의 복원을 보장하지 않습니다.
비정상 종료 뒤 복구는 보장하지 않습니다. 완료 전에 붙여넣으면 원본이 전달될 수 있습니다.

안전하게 처리할 수 없는 파일 약속, 오프라인·읽기 불가 파일, 사용할 HEIC 데이터나
안전한 HEIC 파일 URL 없이 Photos 자산 참조만 있는 입력은 지원하지 않습니다.
동영상은 변환하지 않지만, `.photoslibrary` 동영상 URL 등으로 원본 복원을 보장할 수
없으면 사진을 포함한 전체 혼합 캡처를 거절하고 클립보드를 교체하지 않습니다.
지원하지 않는 입력은 수정하지 않은 원본을 내보낸 뒤 Finder에서 복사하세요.
Live Photo의 동영상은 변환하지 않습니다.
수신 앱마다 지원하는 클립보드 표현이 다르므로 모든 항목·모든 앱의 붙여넣기를
보장하지 않습니다. 문제가 발생하면 macOS·앱 버전, 복사 출처, 수신 앱과 재현 절차를
[공개 이슈](https://github.com/jaehunshin-git/heiccy/issues)에 남겨 주세요.
개인 사진이나 클립보드 원문 대신 개인정보 없는 재현 자료를 사용합니다.

JPEG 출력은 SDR입니다. 지원하는 Apple HDR 게인 맵이 있는 HEIC는 macOS ImageIO를
통해 16비트 HDR PNG로 변환할 수 있습니다. HDR 보존은 원본과 OS 지원에 따라 달라집니다.
기본 메타데이터 정책 `safe`는 가능한 범위에서 GPS와 XMP를 제거합니다.

메뉴바 좌클릭은 현재 클립보드 패널, 우클릭은 일시정지·설정·종료 메뉴를 엽니다.
앱을 Finder·Spotlight에서 다시 열면 패널을 표시합니다. 설정은 저장되지만
일시정지는 현재 실행에만 적용되므로 다음 실행에서는 자동 변환이 켜집니다.
