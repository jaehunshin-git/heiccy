# heiccy 1.0.0

첫 macOS 정식 배포를 준비합니다. 이 문서는 릴리스 노트 초안이며 게시 완료를 뜻하지 않습니다.

- HEIC 클립보드를 JPEG·PNG로 자동 변환하고 ⌘V로 붙여넣습니다.
- 메뉴바 좌클릭으로 현재 변환 상태를 확인하고 우클릭으로 일시정지·설정·종료합니다.
- Apple Silicon arm64·macOS 15 이상을 지원합니다. Swift·macOS 기본 이미지 기능으로 변환하며 Python 런타임이나 외부 코덱을 포함하지 않습니다.
- 원본 파일을 유지하고 변환 실패·새 복사가 발생하면 오래된 결과를 게시하지 않습니다.
- 지원하는 Apple HDR 원본은 16비트 PNG로 보존할 수 있으며 JPEG는 SDR입니다.

## 설치와 업데이트

같은 릴리스의 `heiccy-1.0.0-arm64.dmg`와 `.sha256` 파일을 내려받습니다.

```bash
shasum -a 256 -c heiccy-1.0.0-arm64.dmg.sha256
```

DMG에서 `heiccy.app`을 Applications로 복사합니다. 이전 앱을 먼저 정상 종료하고
기존 번들은 백업한 뒤 교체하세요. `HEIC Converter.app`에서 바꾸는 경우 파일명이
달라 자동 교체되지 않습니다. 번들 ID·설정 키를 유지하며 저장한 변환 옵션을 이어 읽습니다.
자동 업데이트는 제공하지 않습니다.

## 첫 실행과 제한

ad-hoc 서명이며 Developer ID 서명·Apple 공증은 적용하지 않았습니다. 처음 실행한
뒤 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기를 사용합니다.
[Apple 공식 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.
Photos 자산 참조·파일 약속·오프라인 파일은 지원하지 않으며 수신 앱의 표현 선택에
따라 붙여넣기 결과가 달라집니다. 지원 범위는 [한국어 안내](https://github.com/jaehunshin-git/heiccy/blob/main/README.md)를 확인하세요.

앱과 PyPI는 독립적으로 릴리스합니다. Python 패키지 이름 `heic-converter-tui`,
명령 `heic-converter`, 소스 버전 `0.3.0`은 이번 앱 배포로 바뀌지 않습니다.
앱은 프로젝트의 MIT 라이선스를 따르고 macOS 기본 구성 요소를 시스템에서 로드합니다.
별도 Python CLI/TUI의 의존성은 각각의 라이선스를 따릅니다.
